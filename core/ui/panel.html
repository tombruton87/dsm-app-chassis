    2. 
        
  2. Under Custom Header, Create → WebSocket.
    3. 
        
  3. Control Panel → Security → Certificate → Settings: give that reverse-proxy entry your certificate.
    4. 
        
  4. Here: set the address to https://your.domain, tick Behind DSM's reverse proxy, save.
